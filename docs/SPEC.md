## 0. 一句話

《山海有形》（舊名《寫意》）是一個**由漢字構成的 2D 開放世界生存沙盒**：一張紙落在海上，紙上的字活了；你是其中一個「人」字。取木、取棉、取石子；砌磚、造床、磨劍；山裡有煤有鐵，鐵可打甲、鍛鋼具，鐵礦脈偶出鎢礦，鎢鋼更強。蛇在草木之交，豹狼在林與夜，山間有半友好可馴的鷹，水邊有少見的龜；第十三夜起（依難度為第二十一、十三、九夜），怕光穿牆的「魄」夜行；雨天雨夜會澆壞屋外的燈；附近不時起一片霧障，不帶扇子硬闖就五樣數值各掉一成；海上有吞吐霧障、會撞船的蜃，船頭放上虎豹狼的首骨可鎮船，船毀了要在六十息內游上岸。命、飽、暖、力、愜意五條數值加「膽氣」：八重造船（孤帆或方舟）渡海，十重五件衣甲穿齊便是「山海衣」，卅一重可鑄兩件神兵：陸上的九閽鳴雷、海上的燭龍焚溟。死了落一個荷包，膽氣減六成。純瀏覽器單頁、零依賴、全繁體（台灣用語）、水墨紙本美術。

## 1. 專案約定（不可違反）

### 1.0 名稱
- 標題《山海有形》；起始頁第一行「字裡行間 · 一紙之島」；標語「寫木為舟 · 寫水成淵」；左上紅印四字二乘二。
- **本作屬於「寫意」遊戲系列，是系列第一部**（使用者 2026-10-15 定）。「寫意」是系列名，不是本作的名字；之後可能再出「寫意」系列的其他遊戲，各作的內部識別名都以 `xieyi` 起頭。
- 內部識別名以系列名為準：存檔鍵 `xieyi.save.v5`（第一格；第二、三格是 `xieyi.save.v5.2`、`.3`）／`xieyi.slot`／`xieyi.carry`、`dist/xieyi.html`、`window.XIEYI`、分支 `claude/xieyi-open-world`。**不要改**，改了舊存檔讀不到。

### 1.1 語言
- 遊戲文案、程式註解、README、對話回覆一律**繁體中文（台灣用語）**。玩家可以選簡體（v0.24，見 7.5）：只在顯示那一層轉字，程式、存檔、字庫的鍵一律繁體。
- 字庫鍵值是字本身（鳥、魚、龍、門、燈……），改字時全專案一起改。
- 筆畫數採台灣標準（艹算四畫）。

### 1.2 技術
- 純瀏覽器單頁，**無外部 JavaScript 套件**：Canvas 2D 水墨渲染、字形圖集快取、DOM 做 HUD 與面板。字型從 Google Fonts 線上載入，載不到就退回系統字型（標楷體／文泉驛），遊戲本身照常能玩。
- 原始碼是數個掛在 `window` 上的 `<script>`（也能在 Node 用 `vm.runInThisContext` 載入做檢查）。
- 字型：LXGW WenKai TC、Noto Serif TC（Google Fonts），退回標楷體／文泉驛。
- 只做二維；不做關卡制地圖；渡海由玩家自己開船。

### 1.3 每次更新後必做
1. `python3 -m http.server 8123`，再跑 `NODE_PATH=$(npm root -g) node scripts/smoke.mjs`，**全部 PASS、零報錯**才算完成；動到生成規則時另跑 `node scripts/gen-check.mjs 80`，八十座島都要「玩得下去」。
2. 動到 `src/glyphs.js` 的規則表時，跑 `node scripts/spec-tables.mjs` 重產本文件的資料表，並對照改寫相關段落。
3. `python3 scripts/build-single.py` 產出 `dist/xieyi.html`（已 gitignore），**發佈到同一個 Artifact**，不要另開新的。
4. 回覆裡用這個格式附上入口，網址獨立成行、後面不接任何文字（這樣才會顯示成可點的卡片）：

   **遊戲入口（點開即玩）：** https://claude.ai/artifact/AaW9h52xsssPP5beWgBErX

5. 提交、推到分支 `claude/xieyi-open-world`，然後**直接合進 `main`**（開 PR、合併，不用等人審；PR #1 在 v0.10、PR #2 在 v0.12.1 合併）。GitHub 首頁顯示的是 `main`。

### 1.4 位置
- 規則表：`src/glyphs.js`（`DB` 字庫與取物、`ITEMS` 物品與工具、`RECIPES` 配方、`COOK` 灶、`PLACES` 地標、`STELES` 碑文、`naturalTile`／`baseTile` 地形）。
- 數值：`src/game.js` 頂部常數與 `updateStats`；天氣常數在 `src/world.js` 頂部；生靈的命在 `DB`，撲咬與毒咬間隔在 `src/entities.js` 的 `maul`／`bite`。
- 世界：`src/world.js`；生靈：`src/entities.js`；畫面：`src/render.js`；音效：`src/sfx.js`；雜項：`src/util.js`。
- 頁面：`index.html`、`style.css`；測試：`scripts/smoke.mjs`、`scripts/gen-check.mjs`；文件資料表：`scripts/spec-tables.mjs`；打包：`scripts/build-single.py`；截圖：`docs/screenshot-*.jpg`。

### 2.2 關鍵決策與理由
- **為什麼改名《山海有形》**：「寫意」是最初組字造詞版本的名字（寫出意思），機制拿掉後只剩畫論裡「寫意」的第二層意思撐著，調性偏閒適、辨識度低、不說類型。「山海有形」三層意思：山就是「山」字、水就是「水」字，山海有形是因為象形字有形；《山海經》本來就是用文字替山海造形，山海衣、獸群、魄都接得上；又翻了老子「大象無形」。「字裡行間」意象最貼（玩家就住在一行行的字之間，「行」又讀作行走），但 Steam 已有漢字解謎《字里行间》Between the Lines，同題材撞名，所以降為副標：起始頁第一行「字裡行間 · 一紙之島」，標語「寫木為舟 · 寫水成淵」照舊。內部識別名（存檔鍵、檔名、全域變數、分支）維持 xieyi。後來使用者把「寫意」定為系列名：《山海有形》是「寫意」系列第一部，之後可能再出系列其他作品，所以 xieyi 這個前綴是系列的，不是舊名的殘留。
- **為什麼不靠組字造詞推進**：開放世界裡「組出有效的詞」缺少明確目標，玩家摸不到進度；改成「採集、製作、避難、探索」的循環，組字只留在美術與世界觀。
- **侵權考量**：Steam 上的《文字遊戲》是關卡制解謎；本作是開放世界生存，只共用「漢字構成世界」這個不受保護的點子，表達（美術、文案、機制、關卡內容）全部自創，不引用其謎題與文字。生存循環參考 Minecraft／飢荒屬玩法慣例，不構成侵權。
- **擋路靠格子本身**：獸的 `canStand` 不能站上 walk 為 0 的格（磚）、門、屋內、稻草人範圍，一圈磚加一扇門就是避難所，不另判「封閉」。
- **魄只怕光，不怕牆**：牆擋獸、光擋魄，兩套準備。
- **昏迷是用五倍速跑同一個更新迴圈**：醉果的一刻鐘裡世界照常。
- **荷包與囊分開命名**：囊是身上的背包，荷包是死後落地的那一包。
- **種子與真隨機分開**：島的地形、地標、碑、礦叢走種子，同一島號每次長得一樣；天氣、雨澆燈、馴鷹、煉丹、龜卜、鎢礦、驚蛛這類「天意」走 `U.trueRand()` 或 `Math.random()`，同一座島每次玩都不同。
- **數值一律取整**：凡是會算出小數的數值都四捨五入到個位再用、再顯示（見 10.3），玩家看到的數字就是實際算的數字。

## 3. 世界

### 3.1 時間
- 一天 `DAY = 300` 秒（遊戲時間；v0.17 從 240 加長到 300，v0.28 到 375，v0.29 使用者定回 300；`src/game.js` 與 `src/world.js` 各有一份要一致）。**一日從半夜算起**（v0.29）：`dayT = (time % DAY) / DAY`，0 是子夜、0.25 日出（卯時）、0.5 正午、0.75 日落（酉時）。凌晨的黑夜佔 25%、白天 50%、晚上的黑夜 25%。新島從 `MORNING`=0.26（大清早）開始。
- 白晝度 `daylight = smoothstep(DAWN − TWILIGHT, DAWN + TWILIGHT, t) × (1 − smoothstep(DUSK − TWILIGHT, DUSK + TWILIGHT, t))`，`DAWN`=0.25、`DUSK`=0.75、`TWILIGHT`=0.06；`darkness = 1 − daylight`。`isNight()` = dayT ≥ 0.75 或 < 0.25，正好是 daylight 過半的界線；睡覺從 DUSK 起、到 DAWN 前都睡得著，醒在 DAWN + 0.01。v0.28 是 `DAWN`=0.02、`DUSK`=0.52（一日從日出前算起）。
- 夜數 `nightNo`：dayT ≥ DUSK 時為當日，否則為前一日（第 13 日的夜是「第十三夜」）。
- 時辰：子丑寅卯辰巳午未申酉戌亥，`hour = dayT × 24`（v0.29 起一日從子夜算；之前 `(6 + dayT × 24) % 24`）。
- 潮汐：dayT 在 0.37–0.67 為**退潮**（灘＝沙），其餘**漲潮**（灘＝水）；v0.29 跟著一日的起點挪了 0.25（之前 0.12–0.42）。
- **舊存檔**（v0.29，存檔沒有 `dayLen` 或不等於 `DAY`）：日數不換算——第幾日照存檔摘要 `brief.day`（沒有摘要就用 `floor(time / DAY)`）——時間設成那天的 `MORNING`。存著的絕對時刻（作物與再生的計時、稻草人、魚梁、漁網、雨、霧、首骨、龜卜的無魄期、神兵減益的下一次、愜意加快）一起挪同樣的差（`world.timeShift`），剩多久還是多久。
- 天氣（`src/world.js`）：雨不分晝夜。第一場雨在 `DAY×1.5 + 真隨機×DAY×2.5`（不早於第二日）；一場雨下 `RAIN_MIN`=¼日 到 `RAIN_MAX`=1 日，停後隔 `RAIN_GAP_MIN`=1 日 到 `RAIN_GAP_MAX`=4 日再來。時間都用 `U.trueRand()`（crypto，真隨機，不走島的種子），所以同一座島每次玩雨都不同。`world.raining()` 為真時：狀態列多一「雨」字、畫面一層淡墨與斜雨絲、低通噪聲雨聲（靜音與暫停時收起）、雨起雨停各一則提示。
- 雨澆燈：下雨時每息一次，玩家放的每盞燈（`world.lamps`，底稿裡的燈塔不算）若在**屋外**，各擲一次真隨機，中了就變回白紙、消失，並提示座標；機率看難度（`DIFF.*.lampP`，開局寫進 `world.rainLampP`：簡單 1/4500、一般 1/2500、困難 1/800；v0.18 前一律 `RAIN_LAMP_P`=1/1500）。**屋裡**的判定 `covered(x, y)`：從燈的四鄰順著能走的格子漫延（不可通行的字擋住，門雖能走也算牆），`ROOM_LIMIT`=121 格內圍得住就是屋裡；漫出去就是屋外。所以嵌在牆上的燈算屋外；山、水圍成的小天地也算有遮蔽（取捨見 12.1）。
- 霧障（`src/world.js`）：第二日起每日兩擲、各 25%，真隨機，詳見 5.16。
- 無頭測試環境約 12–30 fps，單幀 dt 上限 0.05 秒，所以遊戲時間可能慢於真實時間；測試一律輪詢條件，不用固定等待。

### 3.2 島的生成
- **沼澤**（v0.28）：`naturalTile` 在灘之上不遠（h < `BOG_H`=0.47）、夠濕（m > `BOG_M`=0.63）、再一層噪聲過 `BOG_F`=0.73 的地方長「沼」。極少見：四十座島裡約七成有，平均八格、多的三十來格，約佔陸地的千分之一。走得慢（walk 0.3），見 5.15。
- 座標 `(x, y)`，島中心在原點，`ISLAND_R = 85`、海的盡頭 `SEA_EDGE = 113`（v0.11 起面積加倍，邊長 ×√2；原本是 60 與 80）。噪聲的頻率沒變，所以島上的地形起伏、林與山的團塊大小跟以前一樣，只是多了一倍的地方。地形由三組 fbm 噪聲決定：
  - 高度 `h = fbm(x/64, y/64, seed, 5) − smoothstep(0.55, 1, dd) × 0.6 + (1 − smoothstep(0, 0.3, dd)) × 0.06`（`dd` 為到中心距離 ÷ 60）。
  - 濕度 `m = fbm(x/48 + 300, y/48 − 300, seed + 17, 4)`；溫度 `t = fbm(x/150 − 700, y/150 + 700, seed + 29, 3)`。
  - 每格另有隨機數 `d = rand2(x, y, seed + 5)`、礦脈隨機數 `o = rand2(x, y, seed + 11)`。
- `naturalTile` 規則（由上而下）：
  - `h < 0.33` 淼（深海）；`h < 0.395` 水（淺水）；`h < 0.415` 岸：d<0.8 沙、<0.93 礫、否則石。
  - `h > 0.69` 高山：d<0.75 雪，否則 o<0.0432 鐵、o<0.0932 煤、其餘山。
  - `h > 0.645`：d<0.72 時 o<0.0324 鐵、o<0.0724 煤、其餘山；否則 o<0.03 煤、其餘石。
  - **鐵多 8%**（v0.30 使用者定，`IRON_P`=1.08）：零星鐵礦脈的門檻 0.04／0.03 ×1.08，煤的區間寬度不變；保證的礦叢（煤鐵各十叢，5×5、外圈留一部分）裡，鐵叢外圈留下的機率從 0.4 提到 `IRON_RING`=(15.4×1.08−9)/16≈0.477，平均面積 15.4 → 16.6 格。八十座島實測鐵平均 155.1 → 168.0 格（+8.3%），煤 161.6 不變。
  - `h > 0.615`：d<0.4 石、<0.5 礫、其餘依濕度成木或草。
  - 乾熱（t 高、m 低）區：沙礫石的荒地，點綴石、木、棉、麻、草。
  - 平原：田（濕度高處）、果、花、棉、麻、木、草（棉出現率是原先一半，麻是棉的一半）。
  - 濕區：果、木、林、棉、麻、草；更濕：竹（暖處）、林、木；最濕：森、林。

### 3.4 演替、再生、火、路
- **再生計時器**：取走有 `regrow` 的格子時，排程「若此格仍是取後的字且不是地標格，到時變回原字」：草 30、花 30、棉 150、麻 150、木 180、竹 180、林 180、森 240、果 210 秒。煤、鐵、石、山不再生。
- **隨機演替**（每半秒在玩家周圍 56×56 格採樣 300 格，只對被改動過的格子）：土旁有植物 35% 成草；草旁有兩棵以上木林森果 12% 成木；摘過的果樹（底稿是果）5% 又結果；採過的棉（底稿是棉）5% 又開花；木旁三個以上林森 8% 成林；白紙若周圍 5 格以上非白非水，4% 被「寫回」底稿字（玩家腳邊 1 格內不會）。
- **路**：同一格被踩 6 次，且原字是草土沙花礫、不是地標格，變成「路」。
- **灘不是水**：漲潮時灘讀起來是「水」，但「放在水上」的東西裡，魚梁、船都不能放在灘上；**漁網 v0.18 起可以**（使用者要「在水邊就能放」；灘上的網魚慢三成，見 5.15）；**橋例外**（使用者裁定）：灘上漲潮退潮都能架，架了之後那一格任何潮位都走得過，所以多架幾座橋，漲潮也走得到燈塔。死在海上時船停在最近的真淺水上；靠岸時若船底下是灘，船停到八格內最近的真水上，找不到就靠不了岸。否則退潮後船與魚梁會擱淺在沙上，堵住唯一一條去燈塔的路。拆回橋與魚梁時，那一格還原成底稿的水或灘（以前會變成白紙，等於憑空多一格陸地）。判定一律看 `world.raw`（灘就是灘），不看 `world.get`（隨潮變）。
- **漲潮困在灘上**：人已經站在被淹的灘上時，可以涉水走到相鄰的灘（不能從岸上開始涉水），所以不會被潮水困死，但燈塔仍然只有退潮走得到。
- **火**：可燃格點燃後燒 `5 + s × 0.45` 秒；每步向鄰格蔓延機率 `flam × 0.05 × 火勢`；燒完成「灰」，灰 25–50 秒後成「土」。灶火旺時算光也算熱。

### 4.3 灶
- 六石成灶。**面向灶按 F 開灶**（v0.14，不管手上拿什麼；要穿衣甲、移工具得先轉開）：一個面板，上面寫「火旺，還能燒 N 息」或「灶是冷的，先添柴」；「柴架」四格（v0.21）擺著存下的燃料，點一格燒一個；「添柴」列出囊裡每種能燒的東西（v0.21 起照 `FUEL` 表：煤 150、精煤 900、木 105、竹 60、棉 75、麻 70、果 45、草 30、花 25、橋 90，舊布衣 `CLOTH_FUEL`=50；v0.21 前木類是筆畫 × 15、煤 120、精煤 300），每種旁邊一顆「存」把囊裡那種整疊搬上柴架（`stoveStore()`：先疊進同種的格、再開空格，每格最多 64，四格滿了就不收）；點柴架的格子是 `stoveBurnShelf(i)`。火最多存 `STOVE_CAP`=999 息（原 900），添了會超過就不添（`fuelFits()`，免得白燒），灶與鼎同一張表、同一個上限。柴架存在 `world.shelves`（存檔 `shelves`）；拆灶時柴架記在囊裡那個灶的 `store` 上（跟櫃一樣，囊要有一格空的），重放還在；灶被別的方式抹掉，柴架一起沒了。「烤、燒、煉」列出囊裡每種 `COOK` 表上有的東西（寫動詞、要幾個、配什麼、得什麼），點一下做一次；冷灶或材料不夠的鈕是灰的。面板開著時世界照常走、火照常燒，剩幾息每息更新，囊或火變了就重畫；`E`／`F`／`Esc`／`Enter` 離開，走開超過一格或灶被拆了自己關。鼎不走面板，柴火與灶同一套，照舊面向鼎選中東西按 F。灶旺時是光（魄不近、虎豹怕）也是熱（暖 +4/秒，兩格內）。

### 4.4 工具與具欄
- 三等五種工具。石器：石刀 30、石劍 40、鎬鋤斧 15，耐久 40（石 1 石子 1 木 1 磨礪）。**鋼具**（鐵 2 木 1 煤 1 鍛造，耗力 10）：石具的 140%：鋼刀 42、鋼劍 56、鎬鋤斧 21，耐久 56。**鎢鋼具**（鎢鋼 2 木 1 精煤 1，耗力 16，飽 ≥ 10）：鋼具的 150%、耐久 200%：鎢鋼刀 63、鎢鋼劍 84、鎬鋤斧 32，耐久 112。用一次減 1，到 0 鈍壞。石子 1 重磨（同一把第一次石子一，再來二、四、八，八為上限，`rg` 記在工具上）復滿：石與鋼具耗力 3，鎢鋼具耗力 8、飽 10。工具類型相同（刀鎬鋤劍斧），採集加速與必需工具的判定不分材質。

### 5.2 神志不清
- 愜意到 0：進入神志不清，畫面泛藍（0.55）。先可控 2 秒，再失控 `min(8, 2 + 歸零秒數 / 10)` 秒，交替；失控時角色朝隨機八方向亂走、不能取放。
- 愜意回到 10 以上解除。愜意 < 20 時畫面淡藍（0.25）預警；< 25 有一次提醒。

### 5.4 毒與連咬
- 敵對的毒咬約 2.67 秒一口（v0.9.2 起放慢四分之一）。咬一口中毒幾秒、每秒多少照字庫的 `bite`／`venomT`：蛇 9 秒、每秒 −1.5（v0.28.1 使用者：發作頻率減半、維持九秒；之前 5 秒、每秒 −3）；毒蛛是蛇的一半，9 秒、每秒 −0.75；毒蟾 5 秒、每秒 −2。畫面泛綠；再咬只取較大的每秒值，秒數取較長的。藥可解；鐵甲、鐵盔、鐵靴三件齊（鎢鋼件同算）則毒不侵（咬在鐵甲上，不算連咬、不中毒；生吃蟾蜍也不中毒）。
- **連咬**：兩口間隔 ≤ 6 秒算連續（不是「六秒內十五口」），連咬第 15 口直接死亡。字庫、碑文、說明一律寫「連咬不斷（兩口相隔不過六息）滿十五口必死」。
- 生吃蟾蜍：飽 +5、中毒（每秒 −2，5 秒）。烤蟾：飽 +10、愜意 +10。
- 中毒的持續傷害不算「挨打」，不加速衣甲損耗。

### 5.5 醉果、發酵、昏迷
- 果只分「果」與「醉果」兩種，不按日分堆：一疊果裡每顆各記摘下的日數（`ds`，由陳到新，長度等於數量），不同日摘的合在一疊。格子上顯示最陳那顆放了幾夜（≥12 夜顯示「將醉」），滑鼠停上去列出每批幾顆幾夜。
- 先吃陳的：吃、合藥、任何消耗果的地方都走 `takeFruit`，每一顆都從所有果裡挑摘得最早的；吃時訊息帶「最陳的那顆，放了 N 夜」。
- 換日時逐顆算：放滿 15 夜的那幾顆變醉果，其餘留著；囊滿放不下的醉果先留在果裡，明天再試。進櫃、落荷包、讀舊檔，每顆的日數都跟著走（舊檔按日分堆的整疊 `d` 補成 `ds` 並合成一疊）。
- 吃醉果：昏迷 60 秒遊戲時間，畫面罩一層「昏」並倒數；期間**以五倍速**跑世界（周圍實體照常活動，玩家看得見但不能操作；餓、冷、毒、獸的傷害與各種回復都照算，所以可能在昏迷中死掉），醒來飽 +2、愜意 +1、力 −5。「不扣血」指醉果本身沒有宿醉傷害。
- 二醉果加一淡水瓶成果酒（+12 飽 +20 愜意，瓶子收回）。

### 5.6 睡
- **窗與睡**（v0.29 使用者定）：睡前用 `world.roomShell(x, y)` 從玩家這格漫延，找出圍住這間屋子的四面與屋裡的面積（`shell.area`，屋裡能走的格數）；`game.windowShare()` = 四面裡窗的數目 ÷ 屋裡的面積，`game.windowBonus(share)` 照 `WINDOW_SAN`：大於 1/5 +20%、大於 1/7 +12%、大於 1/9 +5%（剛好等於不算），睡一覺的愜意從 `SLEEP_SAN`=20 多回這麼多；有加成時另設 `p.sanBoostUntil` = 醒來後一整天，這段時間所有愜意的回復（`game.sanUp()`：愜意自回、製作、讀碑、吃東西、聽見的聲音）都快 5%（`SAN_BOOST`），存檔。不在圍得住的屋裡就照 +20。v0.28 是「窗佔四面的一成／兩成／三成」+25／50／75%。
- 日落後（dayT ≥ 0.75，到次日 0.25 前）面向或緊鄰床按 R；天亮後就睡不著（避免清晨反覆小睡白拿回復）；八格內有魄睡不著，除非三格內有地上的光（燈、火、旺灶；v0.20 起）。
- 跳到天亮後（`DAWN` + 0.01；半夜過後才睡就是同一日的清晨），世界快轉 80 步；暖 100、力滿、飽 −12、愜意 +20（窗的加成見上）、命 +10；清掉虎豹狼蛇蛛魄與野豬；馴了的鷹跟過來；提醒旗標重設。
- 放床即設為家（復活點）。

### 5.7 死亡與復活
- 死因文案：餓死了／凍死了／傷重而亡／毒發身亡／力竭而亡。
- 死時囊、具欄、身上衣甲全部落成一個**荷包**（字「包」）放在腳下或由近而遠找到的第一個陸地可放格（80 格內，找不到放出生點）；在海上死，荷包放到最近的岸上，船停在最近一處船身容得下的真淺水上成「舟」（不停在灘上）。面向荷包按 E 全部取回（放不下的留在荷包裡），耐久與損耗一併帶回。
- 復活：有床在家則床邊，否則出生點；那一格若站不住（被蓋了東西或淹了），改到 40 格內最近能站的陸地；馴了的鷹跟過來；命、飽、暖 60，力滿，愜意至少 50，**膽氣減六成（留四成，向下取整）**，毒與連咬清零，神志清明，時間跳到次日清晨 1.03；清掉虎豹狼蛇蛛魄。荷包裡有耐久的工具與衣甲**耐久對折**（向下取整，至少 1），可重磨、可修補。

### 5.8 光
- **磚擋光**（v0.28）：`world.lightNear(x, y, r)` 找到光源後還要 `world.clear(光源, 這格)` 看得見才算——磚、門、墟（`opaque`）擋，窗不擋。所以屋裡的燈照不出去：屋外的魄不會被屋裡的燈燒掉，屋外的虎豹也不怕屋裡的燈；屋裡的人照樣被燈護著。畫面上也一樣：`render` 的夜色挖洞與暖暈，光源附近有擋光的字時只畫看得見的格子（`litCells` 剪裁）。
- **光照圖**（v0.31，`src/render.js` 的 `lightMap()`）：每幀把畫面上的格子每格取 `LM_S`=2×2 個點，每點算還剩幾成夜色（每道光的衰減：中心 1、半徑 0.55 處 0.7、外緣 0，平滑收尾；多道光相乘，跟以前一層層挖洞的效果一樣）與染上的暖光（照光源的顏色加權：燈 255,192,96、燈塔 255,214,130、火 255,138,58、旺灶 255,158,70、火把 255,172,82、龍 236,214,160），寫進兩張小圖，再雙線性放大蓋到畫面上；暖光只畫有光的那一塊。光被磚、門、墟擋：每個點看它那一格從光源看不看得見，`renderer.sight(world, x, y, R)` 把一道光看得見的格子記成一張表，附近沒有擋光的字就回 null（全看得見），地上的字一變（`world.ver`）才重算。光源再用 'lighter' 疊一個亮芯（`renderer.bloom`）。**雨**：下雨時光照圖照算（白天也算，暖光乘 0.55×雨量），燈照得到的雨絲改畫暖色，雨幕上再用 'lighter' 疊一層暖光，所以雨天裡燈也透出微光。
- 燈帽夜裡若三格內有別的光（地上的燈、旺灶、火、手持的火把蠟燭、龍），蠟燭暫停消耗（燈可開可關之意），光照不變。
- 手持（囊裡選中）才亮：火把光 3、燒 180 秒；蠟燭光 2、燒 240 秒（只在夜裡、拿在手上時消耗，燃盡會提示）。燈帽要戴在頭上（帽格）才亮，光 2，但裡面要有蠟燭：造出來自帶一根（400 秒），夜裡自動燒，燒完變暗並提示；選中蠟燭按 V 續上（一次一根，裝滿 400）。燈帽不疊，囊格顯示剩餘息數。地上的燈光 5（小嶼燈塔 9）、旺灶、火都算光源；龍（光 3）只驅四格內的魄。
- 玩家周圍照明半徑（畫面）：`4.5 − 1.5 × darkness + 手上／頭上的光`。
- 虎豹兩格內有光、或夜裡玩家手上有光就退。狼不怕光。魄：玩家身上的光（手裡、頭上）只把牠逼到六格外，地上的燈、火、旺灶三格內才煙滅（v0.20；之前六格內任何光都煙滅）。魄兩格內，手裡的光每息有一成機會被吹熄、八息後才點得著（`snuffT`，燈帽吹不熄但蠟燭燒三倍快）；被吹熄的火把蠟燭不燃。玩家三格內有地上的光，也算「有光」：魄不蝕心、睡得著。
- 雨會澆壞屋外的燈（見 3.1）：燈是長明的光源，但不是永久的，要嘛蓋在屋裡，要嘛備著火把重做。屋裡的燈與底稿的燈塔不受影響。
- **魄煙滅長膽氣**（v0.32 使用者定）：地上的光或龍煙滅一隻魄時（`entities.js` 呼叫 `game.ghostBurned(e)`），戴著的燈帽少 `GHOST_HAT_COST`=2 息蠟燭；若是夜裡、人在屋外（`indoors()` 為假），膽氣長「這一重」的 `GHOST_COUR`=1%（`levelCost(現在的重數)` × 0.01，照比例、不乘難度加成；算斃敵對，廿二重以後也長），魄的位置飄一個金色的「魄滅 · 膽 +N」。天亮在林外散掉的魄不算。

### 5.9 囊、櫃、堆疊
- 囊 16 格（錦囊可到 28），分「食」「物」兩段顯示，可食的自動排在前段、其餘在後段，兩段共用同一池格子；每格最多 64；工具、穿過的衣甲、燈帽各佔一格不疊；果不按日分疊，一疊裡每顆各記日數（見 5.5）。
- 數字鍵 1–9 選前九格（製作面板開著時改為直接造），Tab／Z／] 下一格，Q／[ 上一格，滾輪也可；點格子選中。
- 櫃：石 4 木 4，放在地上，面向按 E 開，24 格；兩個格網點一下整疊搬過去（E／Esc 合上）。**自動歸類**（v0.19）：開櫃與放東西進去時 `sortChest()` 先把同名、沒耐久的疊併在一起，再按工具→衣甲→建材→食物→其餘材料排，同類按筆畫、同名耐久多的在前（果各疊帶日數，不併只排）。**拆下**（v0.14.1）：櫃裡的「拆下」連東西一起拆回囊裡，東西記在囊裡那個「櫃」的 `store` 上（這種櫃單獨佔一格、不與空櫃疊，格子寫「N 樣」，提示列出裡面的東西），重放回地上東西都還在；空櫃拆回是普通的櫃；裝著東西的櫃不能放進別的櫃；讀檔時櫃裡已不存在的東西丟掉。

### 5.10 衣甲與山海衣
- **五格加一**：襯、褲、甲、盔、靴，另有「帽」格給燈帽（與盔不衝突）。顯示在左側數值條下方：上排襯褲甲、下排盔靴帽，格子裡寫名字與剩餘日數（燈帽寫剩餘息數）。囊裡選中按 F 或 V 穿上（同格原來那件回囊），點身上的格子脫下。**同一類衣甲只能有一件**（身上或囊裡，按名字算）：製作欄標「已有」，再造一件只是翻新（壽命回滿、損耗倍率回 1；燈帽則蠟燭裝滿）。內襯與褲只有布的；甲、盔、靴有布、鐵、鎢鋼三種（v0.9 取消鐵褲）。
- **件數值**：內襯（棉 4 麻 2）減傷 2%、禦寒減半；布褲 2%；布甲 3%；布帽 2%；布靴 1%（布五件共 10%）。鐵甲 14%、鐵盔 7%、鐵靴 5%（加內襯與布褲共 30%）。**鎢鋼甲 22%、鎢鋼盔 11%、鎢鋼靴 8%**（鐵件的 160% 取整，加內襯布褲共 45%），壽命 360 日（鐵與布 180 日），也算鐵件（速度、攻擊、消耗、毒不侵的計法相同）；修補要鎢鋼 1、力 12、飽 15。舊式「衣」當內襯穿。
- **鐵件效果**（按件數比例，三件齊為全額）：移動速度每件 −8.33%（三件 −25%）、傷害輸出每件 +1.67%（+5%）、飽／愜意／力的消耗每件 +2.67%（+8%）；**三件鐵齊毒不侵**。

### 5.16 霧障與扇子
- **一片霧是一塊連續的形**（v0.31 使用者定，`src/world.js` 的 `fogForm()`／`fogCoverage()`／`fogCount()`）：超橢圓 |u/a|ⁿ + |v/b|ⁿ = 1，次方 n 在 2（圓）到 6（方）之間、扁圓 a/b 約 0.7–1.3、斜放一個角度，外框再乘上兩三道慢慢轉的起伏（各 4–14%）；n、扁圓、角度都隨霧齡 `f.age` 慢慢變（`World.newFogShape()` 給每片霧一組速率與相位），所以可圓可方、變化無窮。面積 `FOG_AREA` 16–20 格（十八上下），n 變了就照超橢圓的面積表 `SUPER_K(n)` 重算大小，面積不跟著變。**哪些格算霧**：每格取 5×5 個點看蓋到幾成，超過 `FOG_COVER`=5%（也就是 2/25 起）就算；超過 `FOG_CAP`=30 格時只算蓋得最多的三十格（`fogCount()`）。只算這片霧待得住的格子：陸霧要能走、不是水（`fogLand`），而且**不在圍起來、裡面能走的格子不超過 `FOG_ROOM`=45 格的屋子裡**（`fogRoom()`，門算磚，同一次漫延的格子一起記進 `fogRoomCache`，每步與地上的字一變就清）；別的霧佔著的格也不算。海霧（蜃吐的）同一套形，面積 `SEA_FOG_AREA` 6–10，只蓋淺水深水。
- **何時起**：第二日起，每換一日擲兩次真隨機，每次 25%（`FOG_ROLLS`=2、`FOG_P`=0.25，常數在 `src/world.js` 頂部）；中了就在這一日的真隨機時刻起一片霧。所以一日起零片的機會 56.25%、一片 37.5%、兩片 6.25%，最多兩片。睡覺跳過的時刻若有霧該起，醒來時一起起。
- **在哪**：在玩家 8–28 格外（`FOG_NEAR`）的陸地上找一格當霧心，配一個隨機的形；算作霧的格子不到十格（小島、橋上、屋邊太擠）或碰到玩家腳下與四周一圈，就換個地方（最多八次，都不行記 `fogMiss`）。
- **多久**：放著不管一日（`FOG_LIFE`=DAY=300 息）後自己散，最後二十息漸淡。
- **會動**（v0.31 起連續地飄）：霧心每息挪 1/`fogStep` 格（`FOG_STEP`=6，所以每息約六分之一格，跟以前六息一格的平均速度一樣），方向是風向 `f.ang`；每 `fogStep` 的六到十四成息重新定一次方向（`steerFog()`）：霧心 `FOG_LIGHT_R`=10 格內有光（地上的燈、火場、旺灶、手裡或帽上有光的玩家）就背著最近的光走（略帶偏），沒光就順著風向，風向每次微轉、一成五的機會大轉。每一步（半息）照此刻的位置與形狀重算格子（`placeFog()`）。**v0.32 起爬山渡海都不回頭**（使用者定）：除了圍起來、裡面能走的格子不超過 `FOG_ROOM`=45 格的屋子，什麼格子都算得上霧（陸霧、海霧一樣）；碰上這種屋子，被擋掉的那一塊撐到屋外（`fogCover()`：形的大小用二分法找，讓能待的那部分面積等於原本的，最多撐到 `FOG_GROW_MAX`=6 倍；倍數記在 `f.mul`，畫面照用），往屋子去的就拐成繞著走（偏外 20°，四息內不再拐，`f.turned` 記拐了幾次）；飄到離島心 `G.SEA_EDGE` − `FOG_EDGE`(8) 以外、又往外走時轉回島這邊，免得飄出紙外。v0.31 是「能待的格子不到原本一半就掉頭」，而且陸霧只待在能走的陸地上。霧齡與風向存檔（`fogs` 的第四、五欄：形與 [x, y, 霧齡, 風向]）；v0.31 前的存檔只有格子，照格子配一個面積相當、中心在那裡的形。測試把 `fogStep` 設很大（1e9）時霧不動也不變形。`moveFog(f, px, py)` 留著給測試：定方向後一口氣挪一格的距離。
- **畫面**（v0.31）：每幀照霧此刻的位置與形狀算每格蓋了幾成（`fogCoverage`），每格畫三團白霧（預先畫好的放射漸層 `renderer.puff`），蓋得多的濃、邊上的淡，蓋得少的格子那團霧靠向蓋到的角落，所以邊緣是圓的、整片順著風飄過去，不再一格一格跳；新起的霧一息多淡入，散掉或被吹散的淡出（`renderer.fogSeen`）。霧的重心寫一個淡「霧」字；夜色照樣蓋在霧上。小地圖與大地圖上，見過的霧格塗淡灰。面向霧格時提示列寫「霧障 · 走進去會問你要不要用扇子吹散」與囊中扇子數。
- **走進去**：踏進一片霧的任一格，跳出「霧障」彈窗，世界暫停（不算使用者暫停）。
  - 囊中有扇子：兩個鈕「用一把扇子吹散（N）」與「不用，硬闖」。`Y`／`Enter` 用扇子，`N`／`Esc` 不用。
  - 囊中沒有扇子：只有「穿霧而過」，`Y`／`Enter`／`N`／`Esc` 都是它。
  - 用扇子：扇子 −1，整片霧散掉（不只腳下那格），其餘不變。
  - 不用或沒有：命、飽、暖、力、愜意各掉**當前值的一成**，算到小數點後四位（`FOG_TOLL`=0.1；v0.29 前四捨五入到個位）；命不會因此歸零（扣完至少 1，命本來就不到 1 時不扣）。不算挨打：不擋回血、不加速衣甲損耗、不算連咬。
  - 同一片霧裡走動不再問；走出去再進來才再問一次（`player.inFog` 記著剛付過或剛闖過的那片，存檔）。昏迷、死亡、在船上時不觸發。
- **扇子**：`扇`（十畫），草四木一，耗力 2，製作欄「工具」類；一次性，可疊、帶在囊裡。選中按 `V`：三格（切比雪夫）內最近的一片霧整片吹散，沒有就提示。

### 5.17 海：船的命、獸首骨、蜃、落水
- **兩種船**（`G.SHIPS`）：**孤帆**一乘二（人站上頭那格，船身往下一格），命 120，船頭兩個首骨格；木板 8、船槳 1、船帆 1，耗力 16，膽氣八重。**方舟**二乘三（人站左邊中間那格），命 420，船頭五個首骨格；木板 36、船槳 4、船帆 3、鐵 8、麻布 6、鎢鋼 2，耗力 48，膽氣八重；船快只有孤帆的六成（`speed`：孤帆一步 0.14 秒，方舟 0.233 秒）。放下時船身每格都要是真的淺水（`raw` 與 `get` 都是「水」），沒被別的船、網、地標佔著；放下後船身每格寫成「舟」，畫面上畫成一個佔整個船身的大「舟」字，船頭有首骨就寫個小「骨」。船身任一格被改掉（取走、改字），整艘船沒了。
- **船的命**：新造的滿命；停著的船記在 `world.ships`（錨點、種類、命、首骨、修過幾次、船身格子），上船時跟著人走（`player.ship`），靠岸、死在海上停船時再找一處船身容得下的真水停回去。**修船**（面向停著的船選中木板按 `F`，或在船上選中木板按 `V`）：每次回滿命的四分之一（`SHIP_REPAIR_FRAC`，孤帆 30、方舟 105），但**第 n 次修要 n 塊木板**（`repairs` 記在船上，跟著船走，造新船歸零）；木板不夠就修不了，提示會寫下一次要幾塊。舊存檔的單格大船讀進來當孤帆（船身向下或向上找一格水，找不到就沒了）；囊、櫃、荷包裡的「大船」改成「孤帆」。
- **行船**：船身跟著人走，每一步船身每格都要是水（漲潮的灘也算）且不壓到別的船；過不去會提示「船身過不去」。人站的那格撞到能走的陸地就靠岸，船停在原地（船身要容得下真水，找不到就靠不了）。方舟二乘三，窄水道過不去、靠岸也挑地方，是它的代價。
- **出海先問**：膽氣不滿卅一重（`SEA_WARN_LEVEL`=31，神兵的門檻）時面向船按 `E`，跳出「出海？敬勇者之無畏！」彈窗（世界暫停）：第一行「建議卅一重、帶上神兵再下海」，再寫膽氣幾重、海上有蜃、船頭有沒有首骨；「照樣出海」（`Y`／`Enter`）或「回頭」（`N`／`Esc`）。
- **獸首骨**：殺虎、豹、狼，各有 16%（`SKULL_P`，v0.21 起真隨機 `U.trueRand`；原 35%）的機會掉該獸的首骨，掉了一個或兩個（兩個的機會 30%，`SKULL_TWO`）：`虎首骨`、`豹首骨`、`狼首骨`。放在船頭（在船上選中按 `V`，或面向停著的船選中按 `F`）：虎三日、豹二日、狼一日內蜃不敢撞船。首骨**不是燒的，是鎮的**：每個首骨從放上去那一刻起各鎮各的，時間到了**風化**、自己掉，空出格子（船上的那艘會提示「某首骨風化了」）。幾個同時放著就一起鎮，船被鎮住的時限是最晚風化的那一個。孤帆最多兩個、方舟最多五個（`slots`），放滿了再放會被拒。提示列寫船頭有哪幾個（n/格數）與最久鎮到幾日後。鎮船的時限照世界時間走，不論船停著還是開著。
- **蜃**（`蜃`，十三畫，紅字大字）：只在玩家行船或落水時，每一點五息有 1/160 的機會（`ents.seaP`，平均約二百四十息一頭），從十到十六格外的深海（淼）浮上來，一次只一隻；浮上來時提示方位步數。命 900；只能待在水上。
  - 十四格內追玩家（0.4 息一步，比船慢）；貼著船（一格內）時每 2.5 息撞船一下 25（乘難度的受傷倍率），船命歸零即**船毀**。船頭有首骨鎮著就不撞，三格內還會退開，並提示一次「船頭的某首骨鎮著，蜃不敢近」。
  - 玩家落水時改咬人，一口 30（照一般撲咬算：衣甲減傷、山海衣、難度都乘上）。
  - **吞吐霧障**：每 16–26 息一次，若玩家在海上且在十六格內，往玩家那邊二到五格處吐一片 6–10 格的海霧（只蓋水，不蓋玩家腳下那格），九十息散。海霧與陸上的霧障同一套規則：船開進去或游進去一樣跳出彈窗，問要不要用扇子。蜃死時，海上的霧全部收回。
  - 擊敗：膽氣 +40，海霧收回。九閽鳴雷打牠減半；燭龍焚溟全傷（見 4.4）。從船上可以面向牠按 `E` 用手上的兵器打。
- **船毀與落水**：船命歸零，船沒了（不留舟），玩家落在原地的水裡，**六十息**（`SWIM_TIME`）內要游到岸上，否則溺死（死因「沒能游上岸，溺死了」）。提示列與狀態列倒數，並寫出最近的岸在哪個方位、幾步（每零點四秒重算一次）。
  - 游泳：水與淼都能游，一步 0.32 秒；走上任何能站的陸地就算上岸。
  - 游泳時飽、愜意、力的一切消耗 ×2（`SWIM_DRAIN`，乘在 `ironDrain` 上），力不回、反而每息掉 0.5；武器傷害 ×0.75（`SWIM_DMG`，乘在 `dmgMult` 上，神兵也算）。畫面四周泛藍，人只露半身、一圈圈水紋。
  - 游泳時不能取、放、製作，能吃、能打。昏迷、死亡照常結算。

**小屋**（v0.14，門檻 v0.14.1 改看難度）：牆與門圍起的小空間。`world.roomSize(x, y)`：從這格順著 `passable` 的格子四向漫延（門算牆）數有幾格，超過 `MAX_ROOM`=28 就回 29、牆上門上水裡回 Infinity，每步與每次改格清快取；`world.sheltered(x, y, type)` 問的是「這種生靈被這間屋擋住了嗎」，門檻由難度給（`DIFF.room` 擋獸、`DIFF.ghostRoom` 擋魄，經 `world.roomLimitFor(type)` 回調）：簡單 28／18、一般 18／8、困難 10／0（0 ＝ 牆擋不住魄，只有光）。擋得住的屋裡**不出生那種生靈**（`habitat`）、**那種生靈踏不進去**（`canStand`：獸、鳥、鷹、龍都用獸的門檻，魄用魄的；被擋的魄只能停在門上或牆上打轉）；馴了的鷹與龍被喚到身邊時放在屋外（`freeNear(x, y, true)`，用獸的門檻）。屋子接大到超過門檻、或拆了一面牆，立刻失效。

### 7.5 文字：繁體與簡體（v0.24）
- **選項**：起始頁「難度」下面一列「文字：繁體｜简体」（`[data-lang]`）；暫停面板一顆 `#pause-lang`，繁體時寫「简体中文」、簡體時寫「繁體中文」。選擇存在 `localStorage` 的 `xieyi.lang`（`hans`／`hant`），預設繁體；開頁時讀到 `hans` 就直接轉。
- **只轉顯示**：程式裡的文案、字庫的鍵（鳥、魚、鐵……）、存檔、比對用的字串一律繁體，所以規則與存檔不分文字；切換不必重開遊戲。
- **頁面上的字**（`src/i18n.js`）：選了簡體時，一個 `MutationObserver` 盯著整頁，新加的節點、改過的文字、`title`／`placeholder`／`aria-label` 屬性一出現就轉（在瀏覽器畫出來之前，看不到繁體一閃）；`script`、`style`、`textarea` 與標了 `data-noconv` 的（「繁體」「简体」選項本身、暫停面板那顆）不轉。每個轉過的文字節點記下原字與轉後（`WeakMap`），切回繁體時，還是轉後那串的就放回原字；之後遊戲再寫上去的本來就是繁體。
- **畫布上的字**（`src/render.js`）：字形圖集 `glyph(ch)` 先 `I18N.t(ch)` 再快取（簡繁各自一張）；飄字、小地圖與大地圖上的地名也過 `I18N.t()`。
- **轉法**（`src/hans.js`）：字表 2963 字（OpenCC 的 TSCharacters 與台灣異體 TWVariantsRev，只收常用平面的字），詞表 279 詞（整詞轉跟逐字轉不一樣的，例如乾坤、著名不轉成干坤、着名，繁體與台灣寫法都收）；執行時每個位置先試最長的詞，沒有就逐字，轉過的字串快取。`scripts/gen-hans.py` 產表，並拿遊戲裡每一行文字跟 OpenCC 的 tw2s 整句轉換比對，目前一千五百多行全部一致。
- **字型**：霞鶩文楷 TC 已經有遊戲用到的簡體字，只缺「抡」「阍」兩個（掄、閽），落到簡體備用字型；選了簡體才載思源宋體 SC，`html.hans` 時內文字型 `--ui` 改用 SC。

## 8. 存檔
- **三格**：`localStorage` 鍵第一格 `xieyi.save.v5`（沿用舊鍵，所以舊存檔自動落在第一格）、第二格 `xieyi.save.v5.2`、第三格 `xieyi.save.v5.3`（`Game.slotKey(n)`）；每 20 秒自動存、切背景與關頁也存，存進這局開始時選的那一格（`game.slot`，見聞錄「日子」一行也寫著）。
- **起始頁的格子**：每格寫島號、難度、第幾日第幾夜、膽氣第幾重、死過幾次、存檔時刻（v0.19 起不寫睡過幾夜，`brief.nights` 仍存著；`Game.summary(save)`，文案從存檔裡的 `brief`{day, night, isNight, level, deaths, nights} 來；舊存檔沒有 brief 就從世界時間與膽氣算）。「第幾夜」用魄夜的數法：夜裡寫「第 N 夜」，白天寫「過了 N 夜」，第一日入夜前寫「未入夜」。點格子選它（紅框）；「繼續」讀那格；「落筆」把新島寫進選著的格，格裡有存檔時按鈕先變成「覆蓋第 N 格？」，三秒內再按一次才覆蓋；「刪」同樣按兩次（「真的刪？」）。回車：選著的格有存檔就繼續，空的就落筆。預設選的格：網址 `?slot=N`、上次玩的那格（`xieyi.slot`）、最近存的那格、第一格，依序取第一個有的。

**v0.29 起（使用者定）：所有數值的計算精確到小數點後四位，只有顯示在畫面上才四捨五入。** `U.r4(x)` = 四捨五入到小數點後四位，用在每一個「一次算出來的」數：造成與受到的傷害、毒咬每秒、膽氣（含難度加成、日夜係數、死後留四成、減重）、膽氣門檻 `levelCost(n)` 與累積 `CUM`、命上限、霧障的一成、台撞回、神兵的全傷半傷、耐久對折、修船、蜃撞船、製作與鹿鳥海浪的愜意、存檔裡的數。每幀連續變動的數值（飽暖力愜意隨時間掉、回）照浮點數直接算、不逐幀取四位，免得極小的每幀變化被吃掉，存檔時再取四位。顯示：數條旁的數字取整；提示列、彈窗、見聞錄的數用 `fmt()`，留到小數點後兩位（例如「命 −27.67」）。倍率（回復、攻擊、受傷、損耗速度）顯示成百分比。v0.9.5–v0.28 是「一律四捨五入到個位再用、再顯示」。

- v0.26 我定的細節：L3／R3 原本是見聞錄與睡，使用者把它們給了神兵與彈弓，這兩樣就移到原本沒用的右搖桿上下（上見聞錄、下睡；睡要床又要入夜，誤推只會跳一句話）。非標準手柄沒學過「右搖桿上下」就不用（它的軸 3 常是扳機），學完精靈要等右搖桿回中才認（最後一步就是右搖桿往上）。「收回」回到拿出神兵或彈弓之前手上那把；在神兵與彈弓之間換來換去不改記著的那把，這樣 P 或 Y 一按就回到平常用的工具。記著的那把不存檔。桌面殼選 Electron 不選 Tauri：Electron 自帶 Chromium，手柄行為就是一直在測的 Chrome；Tauri 用系統的網頁核心，Linux（Steam Deck）上手柄支援不穩。存檔資料夾固定成 `xieyi-shanhai`（同 `xieyi.*` 鍵名不改的道理）。
- v0.27 我定的細節：「封存」照字面做——整個拿出遊戲、原樣收起來，而不是留著程式只藏介面（那樣標準手柄還會動、卻沒地方設，更難懂）。收起來的東西放在專案裡的 `archive/gamepad/`，而不是只靠 git 歷史，恢復時照 README 的清單放回即可。v0.26 加的 L／P／Y 是鍵盤鍵，照留。暫停面板開幫助在上面的測試、起始頁開幫助在上面的測試，原本混在手柄測試裡，抽出來另寫成不靠手柄的兩項。桌面版照留（上 Steam 用得到），只是說明裡「用 Steam 測手柄」那節也收進封存。
- v0.33 我定的細節：「最近」取走起來最近（路上每一步的時間加起來，斜走一點三倍、難走的地慢），不是直線最近；人本來就在那格旁邊就只轉身面向它。遠處左右鍵都是走過去（到了再按 E 或 F、或再點一下）；相鄰格照舊左鍵取、右鍵放。會動的只跟生靈，魄摸不著不跟；跟到身旁一格就停，不會自己動手打。
- v0.32 我定的細節：「霧障遇到屋子形狀改變、行駛方向改變、面積不變」我做成：被屋子擋掉的那一塊撐到屋外（整片按比例撐大，讓屋外那部分的面積等於原本的），方向拐成沿著屋子繞（偏外 20°）。霧可以渡海以後，為了不飄出紙外，到了海的盡頭會轉回島這邊。海霧（蜃吐的）同樣不再只待在水上。魄煙滅的獎勵：「當前勇氣重級的 1%」取現在這一重升下一重要的點數的 1%，不乘難度加成（要的是比例）；「室外」指煙滅那一刻你人在屋外；燈帽少兩息是每煙滅一隻都扣（屋裡也扣），沒戴燈帽就不扣。神兵修理「兩倍於鎢鋼」料、力、飽都兩倍。滑鼠走路：使用者只說「可以選擇去哪個格子」，我做成左鍵點兩格以外就走過去（點相鄰格仍是取），右鍵只在身旁放東西。
- v0.31 我定的細節：「P 是武器切換，N 是農具切換（如果 N 還沒用）」：N 已經是靜音，所以農具用 P 旁邊的 O。武器是刀、劍、彈弓、神兵，農具是鎬、鋤、斧；P 的輪替不含神兵（神兵有 L，拿著神兵時 P 照舊是收回）。兩段共用原來的格數：武器排前、農具排後，空格在最後，誰都能用。「舊石器研磨成石子」：製作欄「工具」裡一條「研磨石器」，磨手上那把石器、手上不是就磨囊裡的第一把，得石子二（石器是石一石子一木一磨的，木頭磨不回來），耗力二，照一般製作給愜意與膽氣。光照「優化」我兼顧畫質與效能：牆邊的光從方塊變成柔邊、各種光有顏色、多了亮芯；同時把每幀重算視線的開銷拿掉。霧：「可以一小部分粘到外圍格子裡，只要粘到超過 5% 就算」我用每格 25 個點估蓋了幾成（所以實際門檻是 2/25 = 8%，比 5% 高一點點）；「總粘到的格子不超過 30 個」取蓋得最多的三十格。霧每息飄六分之一格，跟以前平均速度一樣；整片霧走到海邊、山腳、屋邊，能待的格子不到一半就掉頭。舊存檔裡的霧照原本的格子配一個同面積的形。
- v0.30 我定的細節：「鐵器」我讀成鐵甲盔靴與鋼具（鋼具本來就是鐵鍛的），「鎢鋼」讀成鎢鋼甲盔靴與鎢鋼具；以前鋼具、鎢鋼具都用石子重磨，現在改用鐵（與鎢鋼）。神兵（九閽鳴雷、燭龍焚溟）沒動，照舊石子。第四檔之後一直照第四檔（跟石子八為上限同理）。「頻率與面積各高 8%」我做成鐵的總量 +8%：零星礦脈的出現機率 ×1.08、保證礦叢的平均面積 ×1.08，礦叢的叢數不變（叢數再 ×1.08 會變成約 +16%）。舊存檔裡已經生成過的地不變，只影響新島與還沒挖動的地（地形是種子算的，所以舊島沒挖過的山裡也會多一點鐵）。舊存檔的鋼具若用石子磨過，`rg` 照算，下一次的鐵從那一檔起算。
- v0.29 我定的細節：門也算「磚窗門」裡的一員，耐久與窗相同（兩下，剩一下變紅），補法也與窗相同；使用者只說了窗。「一半機會產出花草土」做在放下的那一刻（收進囊，囊滿就算壓壞），拆下時不再給。「當次睡眠提升」與「一整天快 5%」：三檔都給一整天的 5%（使用者只寫在最後一句，我讀成三檔共用）；「一整天」從醒來算 `DAY` 秒，期間再睡一次窗夠的屋子就從新醒來時重算，不疊加。「精確到四位」：每次算出的數取四位，每幀連續變動的數不逐幀取（見 10.3）；提示文字留兩位小數，數條旁的數字取整。舊存檔挪到大清早時，把存著的絕對時刻一起挪，免得作物、稻草人、首骨的倒數被拉長或縮短；挨打的計數窗重設。
- v0.28 我定的細節：野豬不怕火光（怕光的是虎豹），稻草人嚇得住；野牛不怕稻草人。野豬斃之膽氣同豹（15）、野牛 10。油脂比肉難得，所以一份做三根蠟燭（肉做兩根）。無毒蛛惹了仍會咬一口（傷二、不中毒），毒蛛的毒算連咬。龜的「移速漲四成」以龜平常一步的時間為準（一步一息半，逃時約一息一步）；碰到水就算逃掉、消失。野牛撞的磚門窗只限人造的，撞碎後那格變白紙，什麼也不剩；撞的下數不存檔。「嗅覺」七折套在所有會找人的獸（虎豹狼蛇、野豬、毒蛛、惹了的蛛蟾牛），挑釁衝過來的不打折（牠已經知道你在哪）。擋光的有磚、門、殘牆，山石樹木不擋（只照使用者說的磚）。窗佔幾成只數四面的磚、門、窗（床、灶這些擺設不算）。沼澤的出現門檻試過幾組，取四十座島裡約七成有、平均八格。製作欄的樹：一條配方用到好幾樣做出來的東西時，掛在同一大類、用途最窄的那樣底下；同一樣東西有兩條做法（蠟燭、大漁網）各自掛在自己的材料底下。
- v0.16 我定的細節：「人造物品」取 `kind === 'object' && place` 的字，連磚也問（使用者說每次都問；拆一整面牆會問很多次，若嫌煩可以加「這一局不再問同類」）；舟、包、碑不算拆；問之前先過囊滿與力氣檢查；「烤肉和蛇肉回血」我做在烤肉與烤蛇上，生蛇肉照舊傷身（生食傷身的規則不動），數值 +10／+8 取「一點量」，藥是 +35。

### 12.2 已知限制與待辦
- 田只是地形，農事（種果棉麻、節氣）未做。
- 渡海後的下一座島與本島規則相同，尚無差異（島嶼差異：林密、潮汐、寒山，使用者裁定 v0.x 之後再做）。
- 天氣只有雨（雪、風、雷未做）；雨目前只澆燈，不影響火把、灶火與暖。村民未做。
- 日後若有飛行或潛海的敵對生物，九閽鳴雷對牠們無效或減半，另設神兵（使用者已定方向，未做）。
- 島變大以後，走遍八處要的時間大約多一倍；生靈的出生是圍著玩家算的，所以密度不變，但地標之間的空地變多。這是使用者要的，平衡上沒試過。
- 蜃不隨讀檔回來：存檔裡只記牠還在，讀檔時牠散了、膽氣減五重（使用者裁定）；船的命、首骨會留著。
- 數值平衡沒經過真人長時間試玩：八重約需 300 膽氣、十重 437、卅一重 4371；魄無光時約三十秒蝕盡愜意；丹的成功率第四顆起只有 1%／2%，平均五十到一百塊蟾肉才煉得一顆，煉到第五十顆要兩千塊以上，多數玩家大概只會煉到個位數顆；「前五十顆每顆 +3%」這一段實際上很難走完。

### 12.3 這份文件與測試本身的缺口
- v0.15.2 開發途中有一次「塔 reveals the island」連帶見聞錄與存檔三條失敗，重跑即過。v0.17 找到原因：測試在真實時間裡跑，手柄那幾段等了二十多秒，世界走到夜裡、魄近身把愜意吸到零，人「手腳不聽使喚」，`canAct()` 擋掉之後的按鍵；現在各大段開頭先 `calm()`（愜意回滿、回到白天、趕走魄）。
- **文字段落會過時**：十版校訂時找出十多處與程式不符（見抬頭的改版紀錄），都是後來改規則時只改了程式、沒回頭改文件。資料表現在由腳本產生，但人寫的段落仍要靠改規則的人自覺對照；`spec-tables.mjs --check` 只管得到表。
- **真隨機的功能只測了機制，沒測分布**：雨澆燈、馴鷹、煉丹、龜卜、鎢礦的測試都是把機率暫時調成 0 或 1，驗證「中了會怎樣」，沒有驗證長期頻率；雨的頻率（四分之一到一日、隔一到四日）也沒有真人體感。
- **無頭測試幀率低**（8–30 fps），時間相關的檢查靠輪詢。時好時壞的測試至今兩次揭出真問題：復活點站不住（v0.9.7）、船停在灘上堵住燈塔路（v0.9.8，死的那一刻是漲潮還是退潮看幀率）。也可能還有別的時序問題只在快機器或慢機器上出現。
- **測試會互相弄髒世界**：測試都在同一座島上跑，前面挖的水、砌的磚會留給後面；十版起漁網測試會把挖的深水還原，但其他測試沒有逐一清理。
- **改名的撞名檢查只做了網路搜尋**：搜尋引擎對中文結果很弱，定案前仍應在 Steam、App Store 與智慧財產局商標檢索查一次。
- **還有一個沒抓到的偶發失敗**：v0.10 驗收時跑了十次，有一次出現一條失敗，當時只記了總數、沒記是哪一條；之後連續八次全過。之後若再看到，要把整份輸出留下來。

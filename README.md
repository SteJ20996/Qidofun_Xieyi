# 写意 · Xiěyì

> 写木成木，写水成水。一纸之岛。

一个**由汉字构成、可以被"写"出来的生存沙盒**。纯浏览器单页游戏，零依赖，双击即玩。

## 创意在哪

大多数生存游戏的循环是"砍树 → 得木头 → 合成木板"。《写意》把这一层抽掉了，直接用汉字本身当物理法则：

1. **世界即文本。** 一座程序生成的小岛，每一格就是一个字：山、水、木、田、草、沙、雪、果、竹……用的是字而不是贴图。你是一个「人」字。
2. **取字入囊，研字为墨。** 面向一个字按 E，它就进了你的囊，纸面留白。囊中之物可以研成墨，得到与它**笔画数相同**的墨（森 12 画，山只有 3 画）。写一个字也付出笔画数的墨。天地之墨，不增不减。
3. **两种合成，都是汉语本来的结构。** 没有合成台、没有配方书。
   - **组字**（写在地上的字上）：木 + 木 = 林，土上写火 = 灶，田上写木 = 果，日 + 月 = 明，人 + 木 = 休。
   - **造词**（写在囊中之物上）：火 + 把 = 火把，石 + 刀 = 石刀，木 + 屋 = 木屋，草 + 衣 = 草衣，竹 + 筏 = 竹筏，草 + 药 = 草药。鱼和肉放到灶上，就成了烤鱼、烤肉。
   你的物品栏就是一份词汇表。
4. **学字即探索。** 取走没见过的字、合成新字、读碑，都会学会写它。岛上五块碑由近到远各教一个字：把、屋、衣、药、筏。想做火把，得先找到第一块碑。
5. **活下去。** 命、饱、暖三条数值。夜里冷，雪上和水中更冷；久了饿；虎踞深森，夜里出猎，畏火与光。生鱼生肉伤身，灶上烤之则美。命尽则"墨尽"，囊落原地，可以回去取。
6. **一些小诗意。** 月亮只在夜里沉在水面，要从岸边把它"捞"上来；日光落在沙与雪上，白天才拾得到。用「口」困住一只鹿，可以把它收进囊里，放到别处它还是活的——写鹿成鹿。吸空的白纸不会永远留白：天地有常，旧字会慢慢自己长回来。

## 运行

```bash
# 方式一：直接双击 index.html（Chrome / Edge / Firefox 都可以）
# 方式二：起一个静态服务器（推荐，书法字体与存档更稳定）
python3 -m http.server 8123
# 然后打开 http://127.0.0.1:8123/
```

URL 参数：`?seed=123` 指定世界种子；`?autostart=1` 跳过开场直接进游戏（测试用）。

书法字体「马善政楷体」来自 Google Fonts，离线时自动回退到系统楷体，不影响游玩。

## 操作

| 键 | 作用 |
| --- | --- |
| `W A S D` / 方向键 | 走（八方向，面朝最后按的方向） |
| `E` / 空格 | 取：吸面前的字入囊，按住可连取；面向鱼是捉，面向鹿虎是猎（需石刀），面向碑是读碑，面向日/月影是拾取 |
| `Tab` | 在「字」行（字典，写字付墨）与「囊」行（囊中之物，放下不付墨）之间切换 |
| `F` / 回车 | 字行：把选中的字写到面前；囊行：把选中之物放到面前（放在灶上是烤或添柴） |
| `C` | 造词：在选中的囊中之物上写一个字（再按数字选字） |
| `V` | 用：吃掉选中的食物 |
| `X` | 研墨：把选中之物化为墨 |
| `1`–`9` · `[` `]` · 滚轮 | 当前行内选择 / 翻页 |
| `R` | 站在「休」或木屋中休息，睡到天明 |
| `M` · `N` · `H` · `+ -` | 小地图 · 静音 · 帮助 · 缩放 |
| 鼠标 | 左键写/放、右键取（限相邻格） |

## 代码结构

```
index.html      页面骨架与 HUD
style.css       宣纸、墨、朱砂印的界面
src/util.js     哈希、可播种随机数、fbm 噪声
src/glyphs.js   字库（笔画 / 通行 / 可燃 / 发光 / 可食）、组字表、词表、岛屿生成、五块碑
src/world.js    分块世界 = 程序生成底稿 + 玩家差异层；火势、演替、复原模拟；灶的柴火、落下的囊；存档
src/entities.js 鸟、鱼、鹿、虎的行为，日月光影，墨点
src/render.js   水墨渲染：宣纸纹理、带渗墨的字形缓存、昼夜光照、小地图
src/sfx.js      Web Audio 现场合成的笔触 / 吸墨 / 合字 / 虎吼
src/game.js     主循环、输入、取/写/放/造词/研墨/吃/猎/读碑/休息、命饱暖、死亡与复活、HUD、存档
scripts/smoke.mjs  无头浏览器冒烟测试（跑一遍核心玩法并截图）
```

几个值得一提的实现选择：

- **世界只存差异。** 底稿由 `(x, y, seed)` 哈希决定，可复现；岛的边缘是高度场随半径衰减出来的，不是贴边。玩家改动的格子放在一个稀疏表里，存档只有几 KB。白纸"自愈"就是把差异层慢慢删掉。
- **两种合成共用一个动词。** "写在地上的字上"是组字，"写在囊中的字上"是造词，都是 `evalWrite` / `wordFor` 一张表查出来的；灶上的烤与添柴也只是"放"的特例。
- **字形缓存。** 每个字按颜色只渲染一次（先一层模糊的渗墨再一层实笔），之后全是 `drawImage`；逐格的旋转、缩放抖动来自坐标哈希，所以同一个字每次看都长一样。
- **模拟只在玩家附近采样。** 火每半秒按邻格可燃度蔓延，分支因子疏木约 1、林约 1.4、森约 1.7：一把火烧不掉一片疏林，但进了深林就失控。演替每步随机采样 300 格，只作用于被改动过的格子，底稿本身是稳定的。
- **虎的追击速度 0.24 秒/格，你在田上 0.11 秒/格、在森里 0.34 秒/格。** 所以开阔地跑得掉，深林跑不掉——地貌本身就是难度。
- **生存数值的节奏。** 饱约 8 分钟耗尽（两个昼夜）；夜长约 110 秒，暖每秒 −1，所以第一夜没有火就会冻到临界；灶边每秒 +4，屋内 +5，草衣减半，火把减六成。这些数字都在 `updateStats` 一处。

## 取舍与已知问题

- **2D 俯视格子，而不是 3D。** 这是刻意的：规则、世界生成、实体系统与渲染是分开的，之后要做 3D 只需把 `render.js` 换成 three.js 的立体字块，字库与世界完全复用。先把"玩法是否成立"验证出来，再谈视角。
- **平衡只是第一版。** 火势、演替速度、虎的侵略性、饥寒速度、墨量上限这些数字都在一两个常量里，没有经过多人试玩。
- **生存层与《饥荒》一类游戏共享的是类型慣例**（饥饿、体温、昼夜、采集、合成），这些是不受著作权保护的玩法概念；美术、道具名、界面、文案全部是本作自己的表达。详见下节。
- **移动端没有适配**（没有虚拟摇杆），窄屏会隐藏部分 HUD。
- **存档在浏览器 localStorage**，换浏览器或清缓存就没了；每 20 秒、建营地、休息、关页面时自动存。
- 无头浏览器（软件渲染）约 35 fps；真实浏览器应稳定 60。

## 灵感来源与差异

用文字当游戏世界不是新点子：Scribblenauts（写词造物）、Baba Is You（词即规则）、Typoman（字母即物件）、Team9 的《文字游戏》（删推拆组、线性叙事解谜）、《字里行间》（推字块拆合汉字）都在前面。《写意》有意避开它们的表达，往另一个方向走：

- 没有关卡、没有既定剧情；一座程序生成的岛和一套生态。
- 核心不是解谜，而是经济（笔画守恒）与生存（命饱暖）。
- 合成同时用组字与造词两种汉语结构；物品栏就是词汇表。
- 视觉是宣纸、书法、朱砂印，不是黑底白字。

## 路线图（接下来可以做的）

1. **叙事。** 不走勇者救公主：岛是一封没寄出的信，碑文是信里的句子；集齐五句，玩家决定把信写完寄出（被写定）还是留白（留下）。
2. **农事。** 田 → 苗 → 禾 → 米 → 饭；四时节气，雪线随季节上下。
3. **天气。** 雨（灭火、涨水、润土）、风（吹火、吹沙）、雷（点火）。
4. **更多字与词。** 艹 + 田 = 苗，林 + 火 = 焚，小 + 土 = 尘，鱼 + 羊 = 鲜；皮 + 衣 = 皮衣；用「口」围出一圈：国、园、囿。
5. **「人」的社会。** 人 + 人 = 从（跟随者），三人成众（结社）。
6. **多人：同一张纸。** 世界只存差异，天然适合同步。
7. **3D 立体字块版**。

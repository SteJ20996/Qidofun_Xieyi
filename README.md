# 寫意 · Xiěyì

> 鳥棲於山，是為島。一張紙落在海上，紙上的字活了。

一個**由漢字構成的生存與探索沙盒**：收集、製作、砌牆，撐過一夜又一夜；第十夜起，外頭有鬼。純瀏覽器單頁遊戲，零依賴，雙擊即玩。全繁體。

## 玩法循環

1. **取**：面向一個字按 E。樹得木，野棉得棉，碎石地（礫）得石子，石地得石，果樹得果。山與磊要用鎬。
2. **製作**（C，耗力）：磚＝土二草一；門＝木三；床＝棉六木二；灶＝石六；火把＝木一草二；燈＝石二火把一；衣＝棉四；藥＝草三果一；橋＝木四；竹筏＝竹六；魚梁＝竹四草二。
3. **磨礪**：石一、石子一、木一，選方向：刀、鎬、鋤、劍、斧。工具有耐久，鈍了用石子重磨。
4. **放**（F）：磚與門擋得住獸與鬼，砌一圈留一扇門就是避難所。魚、肉放在旺的灶上烤熟；木放在灶上添柴；鋤面向土成田。
5. **睡**（R）：夜裡面向床一覺到天明；附近有鬼睡不著。野果在囊裡放過十五夜變醉果，吃了昏睡過夜，醒來命 −15、當天不回血。
6. **夜**：第十夜起鬼夜行，不畏火光，畏劍（兩下），刀要四下；日出則散。虎畏火光，劍兩下、刀三下。
7. **探索**：地圖（M）只畫走過的地方，登塔可見全圖。島上八處地方各留了一段話，連起來是這張紙的來歷；面向村口的門按 E 可問路。退潮時沙路通往島外的燈。

四條數值：**命**（餓、冷、虎、鬼會耗；吃飽穿暖慢慢回）、**飽**（約十二分鐘餓空）、**暖**（夜裡、雪上、水中掉；灶邊、火把、棉衣回）、**力**（製作耗力，歇著回得快，睡一覺全回；讀碑上限 +10）。

## 操作

| 鍵 | 作用 |
| --- | --- |
| `W A S D` / 方向鍵 | 走（八方向，面朝最後按的方向） |
| `E` / 空白 | 取（按住可連取）／攻擊／捉魚／讀碑讀地標／問路／取魚梁的魚／撿囊 |
| `F` / Enter | 放下手裡的東西／在灶上烤或添柴／鋤地 |
| `V` | 吃 |
| `C` | 製作（數字鍵直接造） |
| `R` | 夜裡面向床睡到天明 |
| `1`–`9` · `[` `]` · 滾輪 | 選手裡的東西 |
| `M` · `J` · `N` · `H` · `+ -` | 地圖 · 見聞錄 · 靜音 · 幫助 · 縮放 |
| 滑鼠 | 左鍵取、右鍵放（相鄰格） |

## 執行

```bash
python3 -m http.server 8123     # 然後開 http://127.0.0.1:8123/ ，或直接雙擊 index.html
```

URL 參數：`?seed=123` 指定世界種子；`?autostart=1` 跳過開場。書法字體「霞鶩文楷 TC」來自 Google Fonts，離線時回退標楷體。

測試與打包：

```bash
NODE_PATH=$(npm root -g) node scripts/smoke.mjs     # 無頭瀏覽器跑一遍核心玩法（需要 playwright）
python3 scripts/build-single.py --page             # 打包成單檔 dist/index.html
```

## 程式碼結構

```
index.html      頁面骨架與 HUD
style.css       宣紙、墨、硃砂印的介面
src/util.js     雜湊、可播種隨機數、fbm 噪聲
src/glyphs.js   字庫（取之得什麼、要什麼工具）、物品與工具、配方、島嶼與潮道生成、五塊碑、八處地標
src/world.js    分塊世界 = 程式生成底稿 + 玩家差異層；潮汐；探索迷霧；小路；火勢、演替、復原；灶、魚梁、落囊；存檔
src/entities.js 鳥、魚、鹿、虎、龍的行為；第十夜起的鬼
src/render.js   水墨渲染：宣紙紋理、滲墨字形快取、大字地標、晝夜光照、迷霧小地圖、全島地圖
src/sfx.js      Web Audio 現場合成的音效
src/game.js     主迴圈、輸入、取／攻擊／放／製作／吃／睡、命飽暖力、鬼夜、死亡與復活、見聞錄、HUD、存檔
scripts/smoke.mjs      Playwright 冒煙測試
scripts/build-single.py 單檔打包
```

幾個實作選擇：

- **世界只存差異。** 底稿由 `(x, y, seed)` 雜湊決定，可複現；玩家改動的格子放在稀疏表裡，存檔只有幾 KB。白紙「自癒」是把差異層慢慢刪掉；摘過的果樹、採過的棉會長回來。
- **潮汐是一種地貌。** 潮道的底稿是「灘」，讀取時按時辰解釋為沙或水。小嶼到島心的直線上，水變潮道、山變石徑，所以燈都走得到，而且只在退潮時走得到。
- **擋路靠格子本身。** 獸與鬼的 `canStand` 不能站上 walk 為 0 的格（磚）、門、屋內，所以一圈磚加一扇門就是避難所，不需要另外判斷「封閉」。
- **鬼不怕光，只怕劍和牆。** 這讓第十夜前的準備有明確目標：砌磚、造門、磨劍。鬼只在玩家周圍 12 到 20 格出生，日出後一秒內散去。

## 取捨與已知問題

- 2D 俯視格子，不是 3D。規則、世界生成、實體與渲染分層，以後換渲染器即可。
- 數值平衡沒經過真人試玩：工具耐久 40、鬼每 1.2 秒傷 12、醉果 15 夜，都是第一版數字，全在 `src/glyphs.js` 與 `src/game.js` 頂部的常數裡。
- 魄（鬼的掉落）還沒有用途。
- 手機沒有虛擬搖桿。存檔在瀏覽器本地。

## 靈感來源與差異

Minecraft（收集、製作、避難所、夜裡的怪）、Don't Starve（飢餓、體溫、日夜）、Team9 的《文字遊戲》、《字裡行間》都在前面。《寫意》的不同：世界與物品都是漢字，介面是宣紙與楷書，地圖是走出來的，故事靠走到那裡讀到。繁體的構形留在字裡：島＝鳥＋山，塵＝鹿＋土，泉＝白＋水。

## 路線圖

1. **農事**：鋤成田之後，種果、種棉；四時節氣。
2. **魄的用途**：集魄驅鬼、或換一盞不滅的燈。
3. **更多鬼**：魑魅魍魎各有脾氣；天氣（雨部：雲、電、雷、霧）。
4. **村民**：人在字典裡，總有一天會走出來。

# 写意 · Xiěyì

> 写木成木，写水成水。一笔一世界。

一个**由汉字构成、可以被"写"出来的开放世界**。纯浏览器单页游戏，零依赖，双击即玩。

## 创意在哪

大多数开放世界的循环是"砍树 → 得木头 → 合成木板"。《写意》把这一层抽掉了，直接用汉字本身当物理法则：

1. **世界即文本。** 每一格就是一个字：山、水、木、田、草、沙、雪……无限的程序生成地貌，用的是字而不是贴图。你是一个「人」字。
2. **会意即合成。** 没有合成台、没有配方书。把一个字**写在另一个字上**，若合于造字之理，就生出新字：木 + 木 = 林，林 + 木 = 森，日 + 月 = 明（一盏灯），人 + 木 = 休（营地），土 + 水 = 田（快速路），水 + 石 = 石（填水）。汉字的构字法就是科技树。
3. **笔画即墨，天地守恒。** 唯一的资源是墨。吸走一个字得到与它笔画数相同的墨（森 12 画，山只有 3 画），写一个字也付出笔画数。合字时至少要付笔画差，所以无法凭空生墨。
4. **学字即探索。** 你每吸走一个没见过的字、每合成一个新字，就学会写它。想写「山」？先走到有山的地方把它吸一口。世界就是你的字典。古碑上刻着更多造字之法，读碑者砚台渐宽（墨量上限 +10）。
5. **一些小诗意。** 月亮只在夜里沉在水面，要从岸边把它从水里"吸"上来（水中捞月）；日光落在沙与雪上，白天才拾得到。虎踞深森，夜里出猎，畏火与「明」。被虎扑中不会死，但墨会溅成几个「丶」散落四周，可以再拾回来。吸空的白纸不会永远留白：天地有常，旧字会慢慢自己长回来。

## 运行

```bash
# 方式一：直接双击 index.html（Chrome / Edge / Firefox 都可以）
# 方式二：起一个静态服务器（推荐，书法字体与存档更稳定）
python3 -m http.server 8123
# 然后打开 http://127.0.0.1:8123/
```

URL 参数：`?seed=123` 指定世界种子；`?autostart=1` 跳过开场直接进游戏（测试用）。

书法字体「马善政楷体」来自 Google Fonts，离线时自动回退到系统楷体，不影响游玩。

## 操作

| 键 | 作用 |
| --- | --- |
| `W A S D` / 方向键 | 走（八方向，面朝最后按的方向） |
| `E` / 空格 | 吸墨：吸走面前的字，按住可连续吸；面对碑是读碑，面对日/月影是拾取 |
| `F` / 回车 | 写字：把当前选中的字写到面前的格子上 |
| `1`–`9` · `[` `]` · 滚轮 | 选字 / 翻页 |
| `R` | 站在「休」上休息，睡到天明 |
| `M` · `N` · `H` · `+ -` | 小地图 · 静音 · 帮助 · 缩放 |
| 鼠标 | 左键写、右键吸（限相邻格） |

## 现在的合字表（v0.1）

| 底字 + 所写 | 结果 | 一句话 |
| --- | --- | --- |
| 木 + 木 / 林 + 木 | 林 / 森 | 双木成林，三木成森，虎踞其中 |
| 水 + 水 | 淼 | 深水，有鱼 |
| 火 + 火 / 炎 + 火 | 炎 / 焱 | 火势更猛、照得更远 |
| 石 + 石 | 磊 | 不可逾越的墙 |
| 日 + 月 | 明 | 灯。夜可照路，虎不敢近 |
| 木 + 人 | 休 | 营地，可睡到天明 |
| 水 + 木 / 水 + 石 | 桥 / 石 | 过水的两种办法；土遇水则散 |
| 土 + 水 / 灰 + 水 | 田 | 走得飞快的路 |
| 木 + 口 | 困 | 墙；口写在兽上则困住它 30 秒 |
| 火 + 可燃物 | 燃烧 | 火起于林，势不可挡；灰 → 土 → 草 → 木 慢慢复苏 |
| 水 + 火 / 燃烧物 | 土 / 灭火 | 水克火 |
| 雪 + 火 | 水 | 雪遇火成水 |

完整法则见 `src/glyphs.js`，加一行就是一条新规则。

## 代码结构

```
index.html      页面骨架与 HUD
style.css       宣纸、墨、朱砂印的界面
src/util.js     哈希、可播种随机数、fbm 噪声
src/glyphs.js   字库（笔画 / 通行 / 可燃 / 发光）、合字表、地貌生成、碑文
src/world.js    无限分块世界 = 程序生成底稿 + 玩家差异层；火势、演替、复原模拟；存档
src/entities.js 鸟、鱼、鹿、虎的行为，日月光影，墨点
src/render.js   水墨渲染：宣纸纹理、带渗墨的字形缓存、昼夜光照、小地图
src/sfx.js      Web Audio 现场合成的笔触 / 吸墨 / 合字 / 虎吼
src/game.js     主循环、输入、吸墨/写字/合字/读碑/休息、HUD、存档
scripts/smoke.mjs  无头浏览器冒烟测试（跑一遍核心玩法并截图）
```

几个值得一提的实现选择：

- **世界只存差异。** 底稿由 `(x, y, seed)` 哈希决定，可以无限、可复现；玩家改动的格子放在一个稀疏表里，存档只有几 KB。白纸"自愈"就是把差异层慢慢删掉。
- **字形缓存。** 每个字按颜色只渲染一次（先一层模糊的渗墨再一层实笔），之后全是 `drawImage`；逐格的旋转、缩放抖动来自坐标哈希，所以同一个字每次看都长一样。
- **模拟只在玩家附近采样。** 火每半秒按邻格可燃度蔓延，分支因子疏木约 1、林约 1.4、森约 1.7：一把火烧不掉一片疏林，但进了深林就失控。演替每步随机采样 300 格，只作用于被改动过的格子，底稿本身是稳定的。
- **虎的追击速度 0.24 秒/格，你在田上 0.11 秒/格、在森里 0.34 秒/格。** 所以开阔地跑得掉，深林跑不掉——地貌本身就是难度。

```bash
python3 -m http.server 8123 &
NODE_PATH=$(npm root -g) node scripts/smoke.mjs   # 需要全局或本地安装 playwright
```

## 取舍与已知问题

- **2D 俯视格子，而不是 3D。** 这是刻意的：规则、世界生成、实体系统与渲染是分开的，之后要做 3D 只需把 `render.js` 换成 three.js 的立体字块，字库与世界完全复用。先把"玩法是否成立"验证出来，再谈视角。
- **平衡只是第一版。** 火势、演替速度、虎的侵略性、墨量上限这些数字都在一两个常量里，没有经过多人试玩。
- **移动端没有适配**（没有虚拟摇杆），窄屏会隐藏部分 HUD。
- **存档在浏览器 localStorage**，换浏览器或清缓存就没了；每 20 秒、建营地、休息、关页面时自动存。
- 无头浏览器（软件渲染）约 35 fps；真实浏览器应稳定 60。

## 路线图（接下来可以做的）

1. **村落与「人」的社会。** 人 + 人 = 从（跟随者），三人成众（结社）。村子里的 NPC 会用自己的字和你交换。
2. **天气。** 雨（灭火、涨水、润土）、风（吹火、吹沙）、雷（点火）。
3. **四时。** 春生夏长秋收冬藏：田里长禾，禾 + 人 = 年？雪线随季节上下。
4. **更多会意字。** 艹 + 田 = 苗，田 + 木 = 果，林 + 火 = 焚，小 + 土 = 尘，宀 + 火 = 灾，鱼 + 羊 = 鲜……用「口」围出一圈：国、园、囿。
5. **形声字的半开放合成**：声旁决定"像什么"，形旁决定"是什么"。
6. **多人：同一张纸。** 世界只存差异，天然适合同步。
7. **3D 立体字块版**。
